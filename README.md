# lajstrom.dev

Source of the [lajstrom.dev](https://lajstrom.dev) landing page for [Lajstrom](https://github.com/lajstrom/lajstrom), an artifact registry on top of any OCI registry.

Plain static HTML and CSS, no build step. Served by GitHub Pages from the `main` branch, root directory. The `CNAME` file holds the custom domain.
